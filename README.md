# A standalone Icom remote antenna tuner controller
![Enclosure Front](https://ve2zaz.net/Icom_Tuner_Ctrl/Enclosure_Front.png)

Have you ever wished you could use an Icom remote automatic antenna tuner, such as the AH-4 or the AT-130 without an Icom transceiver? This repository archives the firmware of the VE2ZAZ standalone Icom remote antenna tuner controller box, which allows to use any brand of radio with an Icom tuner. 

The firmware is designed to run on the RP2040-Zero platform, or on the Raspberry Pi Pico with some GPIO pin re-assignment.
